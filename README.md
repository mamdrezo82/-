# روزیار (RoozYar) — نسخه به‌روزشده

برنامه فارسی راست‌چین برای اندروید، با ذخیره‌سازی محلی و کارت‌های قابل مدیریت.

## تغییرات این نسخه
- آیکون یکسان روزیار در رابط برنامه، آیکون وب‌اپ و آیکون لانچر اندروید (با تولید assetها هنگام ساخت).
- کارت‌های داشبورد قابل افزودن، ویرایش و مخفی‌کردن.
- کارت‌های آماده برای کنکور و مطالعه، کارآموزی، سلامت و ورزش، امور مالی، کتاب‌خوانی، پروژه‌های شخصی و اهداف؛ امکان ساخت کارت شخصی و صفحه مستقل برای هر بخش.
- ثبت جزئیات مستقل برای کارت‌های عمومی.
- شمارنده آب با سقف ثابت ۸ لیوان و تنظیم هدف روزانه تا حداکثر ۸.
- رفع اشکال دکمه انصراف در فرم افزودن/ویرایش کار؛ انصراف نباید چیزی ذخیره کند و عنوان خالی هم پذیرفته نمی‌شود.
- تقویم شمسی تعاملی با نشانه کارها و تعداد انجام‌شده.
- تب پایین شامل خانه، روزانه، تقویم، بخش‌ها و پروفایل؛ کنکور از تب پایین برداشته شده و از کارت خودش باز می‌شود.
- صفحه تنظیمات مستقل با پنج تم، تنظیم آب، اعلان‌ها و پشتیبان‌گیری.
- اعلان‌های محلی اندروید برای کارهایی که زنگشان فعال شود؛ پس از اجازه کاربر، برنامه برای ۳۰ روز آینده زنگ‌های فعال را زمان‌بندی می‌کند.
- پشتیبان‌گیری با پنجره انتخاب مسیر اندروید (Storage Access Framework) یا پنجره Save File مرورگرهای سازگار؛ در مرورگرهایی که انتخاب مسیر ندارند، دانلود به پوشه Downloads انجام می‌شود.
- حذف بخش و کد همگام‌سازی ابری؛ اطلاعات در حافظه محلی دستگاه می‌ماند.
- حذف وابستگی اجباری فونت آنلاین تا رابط بدون اینترنت هم نمایش داده شود.

## سخت‌افزار و پیش‌نیاز ساخت APK
- ویندوز، Node.js نسخه LTS، Android Studio، Android SDK و JDK سازگار با Capacitor 7.
- اتصال اینترنت در زمان اولیه برای دریافت وابستگی‌های npm و Gradle لازم است؛ بعد از build، خود برنامه برای ثبت کارها و استفاده روزانه به اینترنت نیاز ندارد.

## ساخت APK در ویندوز
1. ZIP را استخراج کن.
2. در PowerShell به پوشه `RoozYar` برو.
3. اجرا کن:
   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\build-apk.ps1
   ```
4. اسکریپت وابستگی‌ها را نصب می‌کند، پل JS افزونه‌ها را می‌سازد، پروژه Android را ایجاد می‌کند، افزونه بومی انتخاب مسیر پشتیبان را اضافه می‌کند، آیکون‌ها را تولید و APK دیباگ را می‌سازد.
5. خروجی معمولاً در مسیر زیر قرار می‌گیرد:
   `android\app\build\outputs\apk\debug\app-debug.apk`

اگر قبلاً پوشه `android` را ساخته‌ای، اسکریپت تلاش می‌کند افزونه انتخاب مسیر ذخیره را به MainActivity اضافه کند. اگر قبلاً تغییرات اختصاصی در MainActivity داده‌ای، قبل از اجرای اسکریپت از آن نسخه پشتیبان بگیر.

## اعلان‌ها
در تنظیمات گزینه «فعال‌کردن اعلان‌ها» را بزن و مجوز Android را بده. برای هر کار، ویرایش را باز کن، ساعت مشخص کن و «زنگ یادآوری» را فعال کن. برای زنگ‌های قابل‌اعتماد، محدودیت باتری/پس‌زمینه روزیار را در تنظیمات Android بررسی کن. اعلان‌ها در این بسته به‌صورت زمان‌بندی‌شده برای ۳۰ روز آینده ایجاد می‌شوند؛ اگر برنامه برای مدتی طولانی باز نشود، برای ادامه زنگ‌ها برنامه را دوباره باز کن.

## پشتیبان‌گیری
در تنظیمات یا پروفایل، «انتخاب محل و ذخیره پشتیبان» را بزن. در نسخه Android باید پنجره سیستم برای انتخاب محل و نام فایل باز شود. برای بازیابی، فایل JSON را در بخش بازیابی انتخاب کن. قبل از بازنشانی یا حذف برنامه، از اطلاعات پشتیبان بگیر.

## نکات و محدودیت‌های فعلی
- این بسته سورس به‌روزشده است؛ APK از قبل داخل ZIP نیست و باید روی سیستم دارای Android SDK ساخته شود.
- اعلان و انتخاب مسیر ذخیره به افزونه بومی نیاز دارند و باید روی دستگاه Android واقعی آزمایش شوند.
- داده‌های قدیمی در `localStorage` تا جای ممکن حفظ می‌شوند؛ بخش تنظیمات ابری از نسخه جدید حذف شده و پیکربندی ابری قدیمی دیگر استفاده نمی‌شود.


## ساخت APK با GitHub Actions (نسخه 1.3.0)

1. کل پوشه پروژه را در یک مخزن GitHub بارگذاری کن (محتویات این پوشه، نه فایل ZIP به‌عنوان یک فایل تکی).
2. در مخزن، بخش **Actions** را باز کن و workflow با نام **Build RoozYar Android APK** را انتخاب کن.
3. گزینه **Run workflow** را بزن؛ یا با push روی شاخه `main`/`master` ساخت به‌طور خودکار اجرا می‌شود.
4. پس از سبز شدن اجرا، وارد همان اجرای workflow شو و از بخش **Artifacts** فایل `RoozYar-Android-APK` را دانلود کن. داخل ZIP دانلودی، `app-debug.apk` قرار دارد.

نکته مهم: این پروژه فعلاً اطلاعات را به‌صورت محلی روی همان دستگاه نگه می‌دارد؛ ورود حساب کاربری و همگام‌سازی ابری Supabase در این نسخه پیاده‌سازی نشده است. بنابراین داده‌ها بین دستگاه‌ها خودکار همگام نمی‌شوند. فایل APK نیز تا زمان اجرای موفق workflow ساخته‌شده محسوب نمی‌شود.


## تغییرات نسخه 1.3.0
- دکمهٔ جدا برای ساخت بخش شخصی، در کنار انتخاب کارت‌های آماده.
- تم سفارشی با انتخاب رنگ پس‌زمینه، کارت‌ها، متن و رنگ‌های تأکیدی؛ تنظیمات در همین دستگاه ذخیره می‌شود.
- کانال اعلان اندروید با اولویت بالا و لرزش، به‌همراه دکمهٔ آزمایش اعلان.
- محدودیت اعلان: این نسخه هنوز زنگ ممتد مانند اپ ساعت، انتخاب فایل صدای دلخواه یا کنترل مستقیم بلندی صدای سیستم را پیاده‌سازی نمی‌کند. صدای اعلان را از تنظیمات اندروید تغییر بده.

این سورس در این محیط به APK تبدیل یا روی گوشی آزمایش نشده است؛ ساخت APK از طریق GitHub Actions انجام می‌شود.

### محدودیت مهم هشدار
یادآوری زمان‌بندی‌شده در پس‌زمینه همچنان از اعلان بومی اندروید و صدای کانال اعلان گوشی استفاده می‌کند. صدای آزمایشی داخل برنامه، کنترل بلندی صدای سیستم یا زنگ ممتد و تکرارشونده مثل اپ ساعت نیست. برای آن باید افزونه بومی Android با AlarmManager، مجوزهای دقیق و رابط توقف/تعویق زنگ ساخته و روی دستگاه آزمایش شود.

همگام‌سازی ابری، ورود با گوگل و ذخیره‌سازی بین دستگاه‌ها عمداً در این نسخه پیاده‌سازی نشده‌اند. داده‌ها محلی‌اند؛ برای انتقال از پشتیبان‌گیری استفاده کن.
